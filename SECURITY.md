# Security policy

If you find a security issue on [samyakportfolio.netlify.app](https://samyakportfolio.netlify.app) or in this repository, please report it privately:

- Email **samyakgoel5@gmail.com**, or
- use GitHub's **Report a vulnerability** button on this repository's Security tab.

Please include what you found, how to reproduce it, and its impact. I'll acknowledge reports within a few days. Please don't open a public issue for a vulnerability.

The site's machine-readable contact is at [`/.well-known/security.txt`](public/.well-known/security.txt).
